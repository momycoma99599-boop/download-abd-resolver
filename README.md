# Download ABD Mobile

تطبيق Expo لتنزيل الروابط المباشرة وروابط المنصات عبر خادم استخراج مدمج باستخدام `yt-dlp`.

## ما تم إصلاحه

- لصق رابط YouTube أو منصة مدعومة لا يتطلب إدخال خادم خارجي؛ التطبيق يستدعي `POST /api/resolve` تلقائيًا.
- الروابط المباشرة مثل MP4 وMP3 تُنزّل مباشرة من الهاتف.
- اختيار MP4 أو MP3 والجودة.
- إعداد نهاري/ليلي/حسب النظام، لون التطبيق، مجلد الحفظ، الإشعارات، وخيار السماح بالمحتوى المقيّد عمريًا.
- المحتوى المقيّد عمريًا محظور افتراضيًا. عند تفعيل الخيار، يسمح الخادم فقط بالمحتوى الذي يستطيع `yt-dlp` الوصول إليه بصورة قانونية؛ لا يتجاوز DRM أو الاشتراكات أو الحماية التقنية.

## التشغيل

```bash
pnpm install
pnpm dev
```

يجب تشغيل خادم Node (`pnpm dev:server`) مع تطبيق Expo. في الويب، يُستدل على عنوان API تلقائيًا بتحويل منفذ Metro `8081` إلى `3000`. في الهاتف، اضبط `EXPO_PUBLIC_API_BASE_URL` على عنوان HTTPS العام للخادم.

## خادم الاستخراج

المسار:

```text
POST /api/resolve
Content-Type: application/json

{
  "url": "https://youtu.be/1UFXms4X-AA?t=1994",
  "format": "video",
  "quality": "360p",
  "allowAgeRestricted": false
}
```

الاستجابة الناجحة تتضمن `url` و`title` و`ext`. يُنصح بتشغيل الخادم عبر HTTPS وعدم فتحه للعامة دون مصادقة أو تحديد معدل الطلبات في الإنتاج.

إذا تطلب YouTube مصادقة بسبب قيود الشبكة، يمكن للخادم استخدام ملف cookies مُدار بشكل آمن عبر المتغير `YTDLP_COOKIES_FILE`. لا تضع ملف cookies داخل المستودع ولا تشاركه مع الآخرين.

## ملاحظات مهمة

لا يوجد حل يضمن تنزيل «أي شيء» من كل موقع؛ المواقع قد تستخدم DRM أو تسجيل دخول أو روابط مؤقتة أو تمنع التنزيل. التطبيق يدعم المواقع التي يدعمها `yt-dlp` والتي يسمح المستخدم بتنزيلها، ويعرض خطأ واضحًا عند تعذر الاستخراج.
